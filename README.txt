RIO BRASA WEBSITE - SIMPLE HTML VERSION

This version uses plain HTML/CSS/JavaScript. No Node.js or npm is required.

Main files:
- index.html - Home
- food-menu.html - Food menu
- drinks.html - Drinks menu
- gallery.html - Gallery
- booking.html - Branded booking page
- contact.html - Contact

BOOKING
Online reservations are handled securely by Shift4. The Book a Table buttons open the official Rio Brasa Shift4 reservation page. No PHP/MySQL booking backend is needed.

To preview locally: double-click index.html.
